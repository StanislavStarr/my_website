# Stanislav Sinitsyn — personal website

## Быстрый старт

1. Установите Node.js 24 LTS с https://nodejs.org/ — npm входит в комплект.
2. Распакуйте архив и откройте терминал в папке stanislav-portfolio-next.
3. Установите зависимости и запустите приложение:

~~~bash
npm ci
npm run dev
~~~

Откройте http://localhost:3000. Для остановки сервера нажмите Ctrl+C.
Команды работают на macOS, Windows и Linux. Менеджер nvm необязателен;
если он уже установлен, можно выполнить nvm use.
На локальном запуске переменные окружения не требуются.

## Что реализовано

- Next.js App Router, React, TypeScript, next-intl.
- Английская главная на /, русская на /ru.
- Исходный тёплый дизайн: портрет в игровой консоли, крупная типографика,
  движущаяся строка, магнитные кнопки, шторка при открытии кейса.
- Четыре кейса: eKhonish, RZD Cargo, Client Base, MedTech.
- Каждый кейс доступен по прямой ссылке на отдельной странице.
  При переходе с главной открывается диалог через перехват маршрута Next.js.
  Кнопка Back и Escape возвращают к предыдущему состоянию.
- Услуги: дизайн, веб-разработка, React Native + Expo для iOS/Android,
  PWA и Telegram Mini Apps на React/Vue, доработки, запуск, SEO/GEO.
- Telegram и email; без формы, базы данных и внешнего сервиса отправки.
- Игра загружается отдельным JS-чанком по нажатию. Управление: четыре кнопки,
  Q/E/A/D или 7/9/1/3. Раунд до 20 секунд или до трёх пропусков.
- Управление анимацией и поддержка prefers-reduced-motion.
- Метаданные, canonical, hreflang, sitemap, robots, Open Graph и JSON-LD.
- Локальный SVG favicon и OG-картинка, создаваемая средствами Next.js.

Главная и прямые страницы кейсов генерируются при сборке. Тексты присутствуют
в HTML до запуска JavaScript. Игра и визуальные эффекты — клиентские компоненты.
Диалог кейса использует серверный маршрут Next.js при клиентском переходе.
Дизайн-прототип не встроен через iframe: это отдельные React-компоненты.

## Команды и проверки

~~~bash
npm test
npm run typecheck
npm run build
npm start
~~~

Последние две команды запускают production-сборку на http://localhost:3000.
Не запускайте dev и start одновременно на одном порту.
При работающем сервере в другом терминале:

~~~bash
npm run test:smoke
~~~

Smoke-проверка проверяет страницы EN/RU, серверный HTML, 404, языковые маршруты,
robots, sitemap и OG-картинку. Для другого адреса задайте переменную BASE_URL
синтаксисом своей оболочки. Если проверяете домен и canonical, передайте также
SITE_URL. Unit-тесты проверяют SEO-адреса, индексацию и игровую логику.

## Домен, SEO и публикация

До выбора домена индексация выключена: noindex и Disallow: /.
Это состояние подготовки, а не пароль или ограничение доступа.

Перед публикацией:

1. Скопируйте .env.example в .env.local либо задайте переменные в панели хостинга.
2. Укажите реальный HTTPS-домен без пути:

~~~dotenv
SITE_URL=https://your-domain.com
ENABLE_INDEXING=true
~~~

3. Выполните новую сборку. Поскольку страницы статические, изменение этих
   переменных требует пересборки. Удалите прежнюю тестовую сборку на хостинге.
4. Проверьте canonical, /robots.txt и /sitemap.xml на реальном домене,
   переключение EN/RU и оба контакта.
5. Подтвердите сайт в Google Search Console и отправьте sitemap.
   После запуска отслеживайте запросы, страны и реальные обращения.

Без SITE_URL не генерируются выдуманные canonical, JSON-LD URL и sitemap-адреса.
Без ENABLE_INDEXING=true сайт остаётся noindex даже с указанным доменом.
Для тестовых окружений оставьте ENABLE_INDEXING=false.
Файл env не содержит API-ключей и не нужен посетителям.

Для размещения нужен хостинг с поддержкой Next.js/Node.js, например обычный
Node.js-сервер с npm run build и npm start или платформа с поддержкой Next.js.
Это не архив статического HTML для загрузки на произвольный static hosting:
используются Proxy, next/image и перехватываемые маршруты.
Само приложение пока не опубликовано, домен и аналитика не подключены.

Язык не привязан к стране. Первое открытие / остаётся английским даже при
русском языке браузера. Русская версия имеет собственные canonical.
hreflang: en, ru, x-default → английская версия. Смена языка на странице
кейса сохраняет тот же кейс и открывает полноценную страницу выбранного языка. Копий страниц «под каждую страну» нет.

GEO здесь означает обнаружение и понимание контента генеративным поиском.
Подготовлены понятные услуги, отдельные кейсы, автор и связанные URL.
Специальный AI-файл не добавлялся. Позиции и цитирование не гарантируются.

## Аналитика обращений

Сторонние счётчики и передача данных не подключены. Нажатие на контакт
отправляет только локальное DOM-событие portfolio:contact:
channel (telegram/email), path и locale. К нему можно подключить выбранную
систему аналитики. Сам по себе клик не означает полученную заявку.
Персональные сообщения и содержимое переписки сайт не собирает.

## Продолжение разработки

файлов среды подготовки. package-lock.json фиксирует зависимости; npm ci
восстанавливает их. Дизайн и принятые решения сохранены в docs/PROJECT_PLAN.md.
