## Варианты по Speed Index (решение за владельцем)

Анимация входа входит в закреплённый дизайн («текущий визуал с анимациями мне нравится»), поэтому по умолчанию не трогаем.

- **A. Оставить как есть.** Реальные метрики (LCP 1,8 с, CLS 0) хорошие; Speed Index на ранжирование напрямую не влияет.
- **B. Показывать заставку только при первом визите в сессии** (флаг в `sessionStorage`): повторные заходы и переходы между страницами без задержки. Дизайн сохраняется.
- **C. Сократить задержку запуска анимации заголовка** (сейчас 1 с, `Fx.tsx`). Меняет ощущение анимации.

## Что нужно, чтобы довести замеры до точных
